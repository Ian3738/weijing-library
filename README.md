# 未竟之夢圖書館 · 情意密室逃脫

一款情意成長的網頁密室逃脫遊戲，為**科學資優班「情意發展課程」**設計。

玩家被困在一座神祕圖書館，要穿過七位偉大數學家／科學家／文學家的房間——
J.K. 羅琳、達爾文、拉馬努金、居禮夫人、費曼、約翰·納許、司馬遷。
每位都曾跌落人生低谷；解開與他們生平、專業相關的謎題，收集七塊「心靈碎片」。
最後會發現：**真正困住你的門，從來沒有上鎖。**

七個情意主題：面對失敗 · 完美主義 · 孤獨 · 堅持 · 熱情 · 抗壓與心理健康 · 才能的意義。

## 線上遊玩

👉 **https://ian3738.github.io/weijing-library/**

## 開發說明

- 純前端（HTML / CSS / JavaScript），可直接開啟 `index.html` 離線遊玩。
- **遊戲內容**（劇情、謎題、答案、反思）都在 `data.js`，方便修改。
- 美術由 Gemini `gemini-3-pro-image` 生成（`gen_image.py` / `gen_all.py`），日系漫畫風。
- 角色去背使用 `rembg`（`cutout.py`）。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` / `style.css` / `game.js` | 遊戲本體 |
| `data.js` | 所有可編輯的內容 |
| `images/` | 美術素材 |
